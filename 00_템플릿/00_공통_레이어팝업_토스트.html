공통 레이어팝업 · 토스트

버튼을 누르면 실제 공통 컴포넌트가 동작합니다. 저장 · 수정 · 삭제는 확인 팝업에서 [예]를 누르면 완료 토스트가 나오고, 필수항목 미입력은 [확인] 버튼 하나만 있는 안내 팝업입니다. 처리 결과(저장 · 수정 · 삭제)는 개발 쪽에서 연결합니다.

확인 팝업 · 완료 토스트

구분 저장 수정 삭제 필수항목 미입력
얼럿창 저장하시겠습니까? 수정하시겠습니까? 정말로 삭제 하시겠습니까? 필수항목을 입력해주세요.
토스트 저장되었습니다. 수정되었습니다. 삭제되었습니다. -

토스트 종류

type 사용 예 문구 예시 확인
default 단순 알림 (data-toast-type 생략 가능) 이미 신청이 완료된 교육입니다.
info 처리 결과 안내 (취소, 대기접수 등) 대기접수 되었습니다.
success 저장 · 수정 · 삭제 · 접수 완료 저장되었습니다.
warning 할 수 없는 상태 · 확인 필요 접수 대기중입니다.
error 실패 · 불가 안내 접수가 마감된 교육입니다.
confusing 헷갈리기 쉬운 상황 안내 동일 본당에서 이미 접수된 교육입니다.
시간 지정 문구가 길 때 data-toast-time 으로 표시 시간 지정 (ms, 생략 시 1500) 이미 접수된 교육입니다. 접수 내역은 신청접수 확인 페이지에서 확인해 주세요.

사용 방법

<!-- 토스트 공통 : 기본 1.5초 뒤 사라지며, 토스트 바깥 영역을 누르면 바로 닫힘 -->

<!-- 1. 확인 팝업 + 완료 토스트 -->
<button type="button" data-popup="popupConfirm"
        data-confirm-msg="저장하시겠습니까?"      <!-- "|" 로 줄바꿈 -->
        data-toast="저장되었습니다."              <!-- [예] 클릭 후 토스트 문구 -->
        data-toast-type="success">저장</button>

<!-- 2. 토스트만 바로 표시 -->
<button type="button" data-toast-msg="접수 대기중입니다." data-toast-type="warning">접수대기</button>

<!-- 3. 스크립트에서 호출 -->
showToast("저장되었습니다.", "success");

<!-- 4. 표시 시간 늘리기 (문구가 길 때) : 시간은 ms 단위, 생략하면 1500 -->
<button type="button" data-toast-msg="긴 안내 문구입니다." data-toast-type="info"
        data-toast-time="3000">긴 문구</button>     <!-- 1번의 확인 팝업 트리거(data-toast)에도 같이 사용 가능 -->
showToast("긴 안내 문구입니다.", "info", 3000);

<!-- 5. 팝업 마크업 : 페이지 하단의 .layer-popup-wrap 안에 .layer-popup.confirm 을 둠
        확인 팝업은 [아니오](.close) + [예](.confirm-yes), 안내 팝업은 [확인](.close) 하나 -->
