일정 종류
(extendedProps.type)		 ※ 위 표의 달력 종류 data-type(notice · panel …)과는 다른 값입니다. 일정 데이터의 각 일정에 extendedProps: { type: 'edu' }처럼 넣는 값이고, 그 일정의 라벨 · 점 색을 정합니다.
부서 · 분류별로 edu, event, etc, holiday, dp00 ~ dp17을 같은 자리(extendedProps.type)에 넣습니다. 각 종류의 색과 용도는 아래 "일정 종류별 색" 표를 참고하세요.
일정이 겹치는 날 일정 종류의 우선순위는 edu > event > etc > holiday > dp00~dp17 순입니다. 같은 날 일정이 여러 개면(같은 종류가 여러 개여도) 일정 하나당 알약 하나가 이 우선순위 순서로 위에서부터 쌓이고, 칸 높이가 알약 수만큼 늘어납니다. 같은 날 같은 제목의 일정을 중복으로 내려주지 않도록 주의하세요. 모바일에서는 우선순위가 가장 높은 종류의 색 원 하나만 보이고, 나머지 종류는 작은 점으로 표시됩니다.

notice 달력에 data-status를 추가하면 날짜 아래에 상태 글자가 표시됩니다. 기본은 나머지 날짜는 모두 활성이고, data-status에 적은 날짜에만 상태 글자가 표시됩니다. 오늘 이전 날짜는 자동으로 회색 + 클릭 불가입니다. 데모에서 숫자가 검은 날짜가 활성입니다. 모바일에서는 칸이 좁아 글자가 겹치므로 글자 대신 점(대관완료 파랑 · 접수전 회색 · 불가 빨강)으로 표시하고, 공휴일은 날짜 숫자만 빨갛게 표시합니다. 같은 날 일정과 상태 글자가 함께 있으면 날짜 아래에 공휴일 → 그 밖의 일정(대관완료 등) → 상태 글자(접수전 · 불가) 순서로 위아래로 쌓입니다(9 · 16일 참고).

7. range : 기간 선택 팝업

쓰이는 페이지
  • 15_용문청소년수련장/3_이용_안내/3_대관_신청_step02_신청서_숙박_회원.html (입소·퇴소 기간)

  • 15_용문청소년수련장/3_이용_안내/3_대관_신청_step02_신청서_당일_회원.html (단일 날짜)
  • 15_용문청소년수련장/3_이용_안내/3_대관_신청_step02_신청서_당일_비회원.html (단일 날짜)

입력칸을 누르면 달력 팝업이 열립니다. 입소일 → 퇴소일 순서로 누르고 [선택]을 누르면 입력칸에 YYYY-MM-DD가 들어갑니다. 입력칸을 눌러 확인해 보세요.

아래는 .calendar-wrap에 reverse 클래스를 추가한 버전입니다. 기본이 모두 회색 · 선택 불가이고, data-status에 "on"으로 적은 날짜만 선택할 수 있습니다. 입력칸을 눌러 확인해 보세요.

속성 / 항목 설명
data-in / data-out 값을 넣을 입력칸의 id(#rangeIn). data-out을 생략하면 날짜 하나만 고르는 단일 날짜 모드이고, 첫 클릭한 날짜가 그대로 선택됩니다.
data-status {"YYYY-MM-DD":"wait|full|done|off"}. wait 접수전 / full 불가 / done 대관완료 글자가 표시되고, off는 글자 없이 날짜만 회색으로 표시됩니다. 상태가 있는 날과 오늘 이전 날짜는 선택할 수 없습니다. 아무 표시도 없는 날은 예약 가능입니다.
data-status="변수명" 날짜가 많을 때는 속성에 JSON 대신 전역 변수 이름을 적고, window.변수명 = [ { date: 'YYYY-MM-DD', status: 'on' }, ... ] 목록으로 둡니다. 한 줄에 날짜 하나씩 쓸 수 있고, 날짜 전체(YYYY-MM-DD)로 적기 때문에 몇 달 치든 이어서 적으면 됩니다. 한 페이지에 달력이 여러 개면 변수명을 달리합니다. notice 달력(2 · 3번)도 같은 방식으로 쓸 수 있습니다.
data-holidays ["YYYY-MM-DD", ...]. 공휴일은 빨강, 토요일은 파랑, 일요일은 빨강으로 표시됩니다. window.holidays도 같이 읽습니다.
선택 규칙 첫 클릭은 시작일, 두 번째 클릭은 종료일입니다. 시작일 이전 날짜를 누르면 시작일을 다시 지정합니다. 두 날짜 사이는 회색 띠로 표시됩니다.
사이에 낀 날짜 시작일과 종료일 사이에 상태가 있는 날(접수전 · 불가 · 대관완료 · off)이 끼어 있으면 그 종료일은 선택되지 않습니다. "선택한 기간 사이에 신청할 수 없는 날짜가 포함되어 있습니다." 토스트가 나오고, 누른 날짜가 새 시작일이 됩니다. (데모: 다음 달 7일을 시작일로 하고 10일을 누르면 8·9일이 불가라서 막힘 reverse 도 같아서 선택 불가인 날(목록에 없는 날 포함)이 끼어 있으면 막힙니다. (reverse 데모: 이번 달 9일을 시작일로 하고 13일을 누르면 10~12일이 막혀서 안 됨)
data-max-days 시작일과 종료일을 모두 포함한 최대 선택 일수입니다(data-max-days="5"이면 1일~5일까지). 넘으면 "최대 5일까지 선택할 수 있습니다." 토스트가 나오고 누른 날짜가 새 시작일이 됩니다. 생략하면 제한이 없습니다. 이 데모는 5일입니다.
버튼 .rc-cancel 취소(값 변경 없이 닫기) / .rc-apply 선택(입력칸에 반영하고 닫기). 시작·종료일이 모두 없으면 안내 메시지가 나옵니다.
범례 ul.rc-legend. PC는 달력 아래 하나, 모바일은 달마다 하나씩 복사되어 표시됩니다.
표시 범위 PC는 두 달을 나란히, 모바일은 한 달씩 보여 줍니다. 이번 달 이전으로는 이동할 수 없습니다.
data-status 값 기본 class="reverse"
"YYYY-MM-DD":"on" 글자 없이 선택 가능 글자 없이 선택 가능
"wait" 회색 "접수전" 글자 + 선택 불가 (데모 20 · 21일) 같음
"full" 빨간 "불가" 글자 + 선택 불가 (데모 8 · 9일) 같음
"done" 파란 "대관완료" 글자 + 선택 불가 (데모 12 · 13일) 같음
"off" 글자 없이 날짜만 회색 + 선택 불가. 오늘 이후의 휴관일 등을 막을 때 사용 (데모 26 · 27일) 목록에 없는 날짜와 같음
목록에 없는 날짜 선택 가능 글자 없이 날짜만 회색 + 선택 불가
오늘 이전 날짜 목록에 있어도 자동으로 회색 + 선택 불가입니다.
